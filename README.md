# Schema, vecka 45
###### Fullstack webbapplikation med TypeScript, vecka 1 av 7

## Introduktion

Under kursens första vecka kommer vi att fokusera på TypeScript i React. Vi bygger vidare på våra tidigare kunskaper i JavaScript och React och lär oss hur vi kan använda statisk typning för att skriva tydligare, säkrare och mer lättunderhållen kod.

Vi kommer bland annat att arbeta med grundläggande typer, interfaces, typade komponenter, props, state och funktioner. Vi tittar även närmare på hur TypeScript konfigureras med hjälp av tsconfig.json och hur olika inställningar påverkar vår kod.

Veckan består av både genomgångar och praktiska övningar där vi arbetar direkt i Reactprojekt med TypeScript. Målet är att skapa en stabil grund inför det kommande fullstackprojektet, där TypeScript kommer att vara en central del av utvecklingsarbetet.


## Mål för veckan:

1. Använda grundläggande typer i TypeScript.
2. Skapa och använda interfaces och types.
3. Typa komponenter, props och state i React.
4. Hantera API-anrop med TypeScript.
5. Konfigurera TypeScript med tsconfig.json.
6. Identifiera och åtgärda typfel.
